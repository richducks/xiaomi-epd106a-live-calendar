# AI 操作流程与状态机

| 阶段 | AI 调用 | 修改阅读器？ | 验收标准 |
| --- | --- | --- | --- |
| 0 离线准备 | `python prepare_offline.py --status --all` | 否 | 四目标 `ready=true`；当前系统可缺设备 |
| 1 运行检查 | `python ai_runner.py status` | 否（ADB 服务可能在电脑启动） | `reader.return_code=0`，注意离线 assets 与联网 ADB 区别 |
| 2 设备识别 | `python ai_runner.py inspect` | 否 | 设备型号、Android API、Root 权限可读取 |
| 3 来源备份 | `python ai_runner.py backup --serial <SERIAL>` | 否 | ZIP/manifest 有效，按 `snapshot_complete` 判断是否完整 |
| 4 原包校验 | `python ai_runner.py verify --bundle <ZIP>` | 否 | 返回 0，哈希和路径校验通过 |
| 5 目标检查 | `python ai_runner.py inspect --serial <TARGET>` | 否 | 用户确认目标序列号与硬件 |
| 6 目标保护 | `python ai_runner.py backup --serial <TARGET>` | 否 | 目标阅读器单独备份完成 |
| 7 安装 APK | `python ai_runner.py restore --bundle <ZIP> --serial <TARGET> --approve-install` | **是** | 有用户明确许可，日志报告每个安装结果 |
| 3B 源码归档（可选） | `python ai_runner.py source --project-dir <实际项目路径>` | 否 | 项目源码单独 ZIP；审查密钥后才能同步公开代码 |
| 8 产品验收 | 人工查看 `功能验收清单.md` | 仅人工验收 | 真实日历/省电/触控测试并记录 |

安全原则：本包没有操作 Android 启动分区、恢复出厂、文件系统格式化、Root 回放的功能；不因存在 `fastboot` 命令而允许刷机。

## 正常终端例子

```text
python ai_runner.py status
python ai_runner.py inspect
python ai_runner.py backup --serial 设备实际序列号
python ai_runner.py verify --bundle reader-backups/reader_实际日期.zip
```

每步解析 JSON 的 `ok`、`reader.return_code`、`reader.stderr`。如 `ok=false`，阻断后续修改并报告原因。

## 仅在用户批准后执行

```text
python ai_runner.py restore --bundle 实际备份.zip --serial 实际目标设备序列号 --approve-install
```

离线包的 `vendor/` 目录应先完整准备、校验，再搬到另一台电脑；目标电脑无需接入互联网，但 USB 驱动 / macOS 授权 / Linux udev 权限依旧可能受操作系统影响。
