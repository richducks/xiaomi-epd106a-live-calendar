# v0.3 交付验证记录（2026-11-16）

## 已完成

- Linux 容器内 Python 3.13：`RUN_READER_E2E=1 python -m unittest discover -s tests -v`，**20/20 成功**，其中包含模拟 ADB 的备份-校验-安装-型号不匹配拦截。
- `prepare_offline.py` 对伪造 ZIP / TAR 的提取和路径穿越阻拦进行了单元验证。
- `ai_runner.py` 在缺少 ADB / Python 离线运行时时返回 `ok=false`，并拒绝无用户授权或目标序列号的安装。
- 生成的源码工具包 ZIP 执行 `zipfile.testzip()` 通过。

## 未完成、不得宣称通过

- 四系统真实官方 ADB / Python 二进制**尚未预载**：当前环境无法连接外部下载站。`prepare_offline.py --all --status` 显示四个平台 `ready=false`。
- Windows 10/11 本机、macOS Intel/Apple Silicon 本机、Linux 不同发行版的真实 ADB 执行均未验证。
- Android 真机的 USB 授权、APK 安装、Root 归档、日历壁纸/翻页体验尚未现场验收。
- 这不是厂商 ROM/整机备份，GOLDEN V1.0 的真实设备改造数据未采集。

## 验收结论

交付范围是**跨平台源码 + 下载与封装流程 + AI 控制入口**；完整离线仓需要在用户自己的有网电脑下载并完整运行 `--status` 后才可验收。
